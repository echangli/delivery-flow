## Как сгенерировать

1. Выгрузить события через MCP платформы аналитики (в примере Amplitude —
   `mcp__amplitude__get_events`, `projectId: ⟪ADAPT: id проекта аналитики⟫`, `limit: 500`).
2. Отфильтровать системные события платформы (в примере — с префиксами `[Amplitude]`, `[AppsFlyer]`,
   `[Experiment]`).
3. Сгруппировать по полю `category`, внутри группы отсортировать по `event_type`; в заголовке секции —
   имя категории и число событий.
4. Записать в том же формате таблицы, что выше; обновить **дату снапшота** и общее число событий
   в заголовке файла.

**Регенерация — раз в 2–3 месяца** (владелец — аналитик). Снапшот нужен только как быстрый первичный
индекс для keyword-скана: **источник истины — живая таксономия через MCP**, каждое решение спеки
подтверждается live-вызовом (см. `SKILL.md`, Workflow шаг 2). Устаревший снапшот к дублям не ведёт, но
замедляет первичный поиск.
